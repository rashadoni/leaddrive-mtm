# Route & Field — находки на 23 октября 2026

Проверена установленная версия 3.11.51 / APK1730 на реальном Samsung S23 Ultra.
Исходная версия приложения: `f1bcdcb2c0213eba73da8a10dfd89715b3e40a6d`.
Изменения ниже относятся к тестам. Код приложения и бизнес-логика CRM пока
не менялись: в пройденном цикле задачи дефект продукта не воспроизведён.

| Находка | Исправление | Проверка |
| --- | --- | --- |
| Принудительное центрирование уже видимой кнопки останавливало прокрутку теста | Убрано лишнее центрирование | Общий сценарий пяти вкладок агента PASS |
| Тест ожидал заголовок «Профиль», новое состояние вкладки и прокрутку в начало | Учтены реальный экран, сохранённая вложенная навигация и прокрутка команды | Сценарии агента и менеджера PASS |
| Android Back вместо скрытия клавиатуры закрывал форму результата | Результат отправляется видимой кнопкой без лишнего Back | Завершение задачи Maestro PASS; результат подтверждён на сайте |
| Проверка требовала acceptedAt одновременно со startedAt | Разделены независимое принятие и начало по контракту сервера | Один STARTED и один COMPLETED, статус/version/result подтверждены |
| Список под мобильным токеном менеджера ошибочно принимался за список задач агента | Независимая проверка через обычную веб-сессию менеджера | Точный агент, одна тестовая задача, без дублей |
| Ошибка проверки конечного экрана скрывала первичную ошибку Maestro в отчёте | Результаты JUnit сохраняются до проверки конечного экрана | manager-tabs-v1 сохранил первичную ошибку и FAIL JUnit; исходные отчёты сохранены |
| Изменения только тестов Maestro запускали упаковку и публикацию новой версии APK | Отдельно определяются тестовые/документационные изменения; ручная сборка, код приложения, зависимости и неизвестные изменения по-прежнему требуют APK | Четыре проверки классификации PASS; обязательные Jest/TypeScript не пропускаются |

Пройден сквозной цикл: менеджер создал задачу через настоящий сайт CRM → агент
начал и завершил её через Maestro на телефоне → сайт показал точный результат,
100% и версию 3. В истории по одному созданию, началу и завершению.
Менеджер затем принял результат через сайт: один ACCEPT, версия 4; исходные
результат, исполнитель и времена начала/завершения сохранены.

Вход менеджера, его профиль, команда, карточка нужного сотрудника, локальная
проверка пустой задачи с отменой, планирование, согласования и возврат на
главный экран команды прошли Maestro. На телефоне оставлен менеджер.

Отдельное улучшение: в текущем мобильном интерфейсе менеджера доступна выдача
задачи, а очереди приёмки выполненных задач нет. Этот этап проверен через сайт.
Добавление такой очереди в приложение — расширение возможностей, а не
исправление воспроизведённого сбоя синхронизации.

Визиты, фото, GPS, офлайн и отрицательные проверки доступа пока **NOT RUN**:
для них подготовлен отдельный фиктивный тестовый контур. Проверки PostgreSQL и
полный CI также **NOT RUN**, до публикации проверяемой ветки. Успех задачи и
навигации не означает прохождение всей этой матрицы.
