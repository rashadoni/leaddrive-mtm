# Согласие для тестовой компании

Статус: владелец явно подтвердил публикацию 22 октября 2026 года (Asia/Baku). Опубликован как тестовая политика v1. Используется только в `mtm-attendance-phone`; не является политикой для сотрудников реальной компании.

## Русский

Только для проверки приложения в тестовой компании. При начале и завершении работы вне перерыва приложение передаёт текущие координаты и точность для сравнения с тестовым филиалом. Фоновое отслеживание и сбор координат во время перерыва не выполняются. Данные доступны администратору в истории теста. Согласие на новые измерения можно отозвать в приложении; уже сохранённые данные остаются в истории.

## Azərbaycan dili

Yalnız tətbiqin test şirkətində yoxlanılması üçündür. İşə başlayarkən və fasilədən kənar işi bitirərkən tətbiq test filialı ilə müqayisə üçün cari koordinatları və dəqiqliyi göndərir. Arxa planda izləmə və fasilə zamanı koordinatların toplanması aparılmır. Məlumatlar test tarixçəsində administratora görünür. Yeni ölçmələrə razılığı tətbiqdə geri götürmək olar; artıq saxlanmış məlumatlar tarixçədə qalır.

## English

Only for testing the app in the test company. When starting work or finishing outside a break, the app sends current coordinates and accuracy for comparison with the test branch. There is no background tracking or location collection during a break. The administrator can view the data in the test history. Consent to new measurements can be withdrawn in the app; previously saved data remains in the history.
